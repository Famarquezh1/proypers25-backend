# Proypers25 Spot Performance

Resumen sanitizado del ledger canónico de operaciones Spot reales ejecutadas por el bot.

Fuente: `real_spot_execution_results`, clasificación canónica de rendimiento y `real_spot_config/balance`.
Las conversiones, ventas manuales y reconciliaciones externas quedan separadas y no inflan el PnL del bot.
No contiene secretos, API keys ni credenciales.

Archivo:
- `ops/latest-performance.json`
